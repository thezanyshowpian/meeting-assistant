# UI Specification

> Interface requirements are fixed by the PS; the framework and layout are TBD.

## Required behaviors (fixed)
- Upload a meeting recording
- Start processing
- Show clear processing / failure status
- Display raw transcript
- Display refined transcript **separately** (comparable with raw)
- Display minutes, key decisions, action items
- Download all outputs (human-readable + machine-readable)
- Clear error message for unsupported / empty / unreadable files
